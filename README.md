# Hospital Readmissions Analysis
Analysis of CMS HRRP data across 2,833 U.S. hospitals.

## Live Dashboard
[Click here to open]([your-streamlit-url](https://hospital-readmission-analyzer.streamlit.app/))

## Key Findings
- 83.2% of hospitals penalized under the federal program
- Massachusetts shows highest excess readmission ratio
- Hip/knee replacement has highest readmission rates
- Built companion AI tool: ReadmitRadar

## Tools Used
Python, Pandas, Matplotlib, Seaborn, Streamlit
